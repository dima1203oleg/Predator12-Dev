```typescript
// assistantStore.ts
locale: 'uk-UA', // Головна мова — українська
```

### 2. i18n конфігурація

```typescript
// i18n.ts
i18n.init({
  lng: 'uk',              // Початкова мова
  fallbackLng: 'uk',      // Резервна мова
  resources: {
    uk: { translation: ukUA },  // Українська (primary)
    en: { translation: enUS },  // Англійська (secondary)
  },
});
```

### 3. HTML lang attribute

```typescript
document.documentElement.lang = 'uk'; // <html lang="uk">
```

### 4. localStorage persistence

```typescript
localStorage.setItem('predator-locale', 'uk-UA'); // Зберігається між сесіями
```

## 🎤 Голосова взаємодія

### ASR (Speech Recognition)
- **Мова**: `uk-UA` (українська)
- **Fallback**: `en-US` (якщо українська недоступна)

```typescript
recognition.lang = 'uk-UA'; // Розпізнавання української
```

### TTS (Speech Synthesis)
- **Пріоритет**: українські голоси (`uk-UA`, `uk`)
- **Пошук**: `Ukrainian`, `україн*`
- **Fallback**: англійська

```typescript
// Пошук українського голосу
voice = voices.find(v => 
  v.lang === 'uk-UA' || 
  v.name.includes('Ukrainian')
);
```

## 🌍 Додавання нових мов

### 1. Створити переклад

```bash
touch locales/ru-RU.json  # Російська (якщо потрібно)
touch locales/pl-PL.json  # Польська
```

### 2. Додати в i18n

```typescript
// i18n.ts
import ruRU from './locales/ru-RU.json';

i18n.init({
  resources: {
    uk: { translation: ukUA },
    en: { translation: enUS },
    ru: { translation: ruRU },  // Нова мова
  },
});
```

## 📚 Рекомендації

### Для розробників
- ✅ Завжди використовуйте `t('key')` замість hardcoded текстів
- ✅ Додавайте нові ключі в обидва файли (uk-UA + en-US)
- ✅ Використовуйте змістовні ключі: `chat.placeholder`, а не `text1`
- ✅ Перевіряйте переклади в UI після змін

### Для перекладачів
- ✅ Зберігайте структуру JSON
- ✅ Не перекладайте технічні терміни (API, GPU, FPS)
- ✅ Використовуйте однаковий стиль (ти/ви)
- ✅ Перевіряйте контекст використання

### Для QA
- ✅ Тестуйте обидві мови
- ✅ Перевіряйте довгі рядки (overflow)
- ✅ Тестуйте ASR/TTS для кожної мови
- ✅ Перевіряйте fallback механізми

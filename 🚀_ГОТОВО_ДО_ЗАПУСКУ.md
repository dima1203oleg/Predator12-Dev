## 🔧 TROUBLESHOOTING

### Backend не запускається

**Перевірка:**

```bash
# Перевірити порт 8000
lsof -ti:8000

# Перевірити Python
python3 --version

# Перевірити залежності
cd backend
pip3 list | grep fastapi
pip3 list | grep uvicorn
```

**Рішення:**

```bash
# Встановити залежності
pip3 install -r requirements.txt
pip3 install -r cyber_ace/requirements.txt

# Перезапустити
pkill -f uvicorn
python3 -m uvicorn app.main:app --reload --port 8000
```

### Frontend не підключається до Backend

**Перевірка:**

```bash
# Test backend
curl http://localhost:8000/api/cyber-ace/health

# Перевірити .env
cat frontend/.env.development
```

**Рішення:**

```bash
# Перевірити CORS в backend
# main.py має містити:
# allow_origins=["http://localhost:5173", ...]

# Перезапустити frontend
cd frontend
npm run dev
```

### Помилки в консолі браузера

**Перевірка:**

1. Відкрити DevTools (F12)
2. Перейти в Console tab
3. Перейти в Network tab
4. Перезавантажити сторінку

**Типові помилки:**

- `CORS error` → Перевірити CORS в backend
- `Network error` → Backend не запущено
- `404 Not Found` → Неправильний URL

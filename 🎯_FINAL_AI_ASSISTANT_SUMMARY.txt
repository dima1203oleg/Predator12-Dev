🚀 ШВИДКИЙ СТАРТ

1. Install dependencies:
   cd predator12-local/frontend
   npm install three @react-three/fiber @react-three/drei @react-three/postprocessing d3 zustand react-i18next

2. Run dev server:
   npm run dev

3. Open browser:
   http://localhost:5173/assistant

4. Test features:
   • Press M → speak
   • Type message → Enter
   • Click graph node
   • Switch language (🇺🇦/🇬🇧)

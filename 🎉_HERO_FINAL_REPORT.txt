Дизайн:

   • Responsive breakpoints

🐛 TROUBLESHOOTING

ПРОБЛЕМА: Frontend не запускається
РІШЕННЯ:
   cd predator12-local/frontend
   rm -rf node_modules
   npm install

ПРОБЛЕМА: Граф не відображається
РІШЕННЯ:
   npm install cytoscape @types/cytoscape

ПРОБЛЕМА: Backend не відповідає
РІШЕННЯ:
   pkill -f uvicorn
   cd predator12-local/backend
   uvicorn app.main:app --reload --port 8000

ПРОБЛЕМА: Голосовий ввід не працює
РІШЕННЯ:
   • Використовуйте Chrome/Edge
   • Дайте дозвіл на мікрофон
   • Перевірте .env: VITE_ENABLE_VOICE=true

# Розгортання локального середовища розробки

Цей файл описує швидкий набір кроків для підготовки локального середовища розробки Predator Analytics та встановлення інструментів автопокращення.

1. Базова підготовка

```bash
# Клонуйте репо (якщо ще не клоновано)
git clone git@github.com:dima1203oleg/Predator12-Dev.git
cd Predator12-Dev/predator12-local
```

2. Швидкий скрипт налаштування

Запустіть унизу розташований скрипт, який створить віртуальне оточення, встановить залежності бекенду та фронтенду і поставить pre-commit hooks.

```bash
./scripts/setup-dev.sh
```

3. Pre-commit

Після встановлення перший запуск перевірить і виправить проблеми форматування:

```bash
pre-commit run --all-files
```

4. Dry-run автопропозицій

Для безпечного прогону агента у dry-run виконайте:

```bash
./scripts/auto_propose.sh
```

Файл звіту буде збережено як `.auto_propose_report.txt` у корені проекту і може бути завантажений GitHub Action `autogen-scan`.

5. CI / GitHub Actions

Ми додали workflows для лінту та scheduled dry-run (див. `.github/workflows/`). Щоб дозволити автоматичне створення PR з пропозиціями, потрібно додати секрет `GH_AUTH_TOKEN` з правами репо (режим optional / вручну).

6. Безпека

- Автогенерація створює PR лише в окремих гілках; автоматичного мерджу в `main` немає.
- Рекомендую рев’ю кожного PR від агента перед мерджем.

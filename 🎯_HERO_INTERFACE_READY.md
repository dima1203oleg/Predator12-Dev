## 🔧 НАЛАШТУВАННЯ БЕКЕНДУ

### Очікувані endpoints:

```javascript
// Конфігурація в hero-main.js
const CONFIG = {
  apiUrl: "http://localhost:8000",
  endpoints: {
    chat: "/api/chat", // POST - відправка повідомлень
    events: "/api/events", // GET (SSE) - події агентів
    network: "/api/network", // GET - дані для графа
  },
};
```

### Формат запиту `/api/chat`:

```json
{
  "message": "текст повідомлення користувача",
  "trace": true
}
```

### Формат відповіді `/api/chat`:

```json
{
    "reply": "відповідь AI",
    "networkData": {
        "nodes": [...],
        "edges": [...]
    }
}
```

### SSE `/api/events`:

```
data: Router Agent: Аналіз запиту користувача...
data: Law Agent: Пошук в базі законодавства...
```

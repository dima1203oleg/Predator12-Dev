# ✅ ШВИДКИЙ ЧЕКЛИСТ: НАСТУПНІ КРОКИ

## 📋 ЕТАП 1: BACKEND API INTEGRATION (Пріоритет: HIGH)

### 🔌 Provider Management Endpoints

- [ ] **GET /api/providers**
  - Повертає список всіх провайдерів з акаунтами
  - Response: `ProviderAccount[]`
  - Status: 200 OK

- [ ] **POST /api/providers**
  - Додає новий Provider Account
  - Body: `{ providerId, accountName, apiKey, apiEndpoint, models }`
  - Response: `ProviderAccount`
  - Status: 201 Created

- [ ] **PUT /api/providers/:id**
  - Оновлює існуючий акаунт
  - Body: Partial<ProviderAccount>
  - Response: `ProviderAccount`
  - Status: 200 OK

- [ ] **DELETE /api/providers/:id**
  - Видаляє акаунт
  - Response: `{ success: true }`
  - Status: 204 No Content

---

### ⚙️ Model Configuration Endpoints

- [ ] **GET /api/providers/:id/models**
  - Повертає список моделей для акаунту
  - Response: `ModelInfo[]`
  - Status: 200 OK

- [ ] **POST /api/providers/:id/models/config**
  - Зберігає конфігурацію моделей
  - Body: `{ modelId, config: { maxTokens, temperature, topP, ... } }`
  - Response: `{ success: true, config: ModelConfig }`
  - Status: 200 OK

- [ ] **POST /api/providers/:id/test**
  - Тестує підключення до провайдера
  - Body: `{ modelId, testPrompt }`
  - Response: `{ success: boolean, latency: number, message?: string }`
  - Status: 200 OK

---

### 📊 Statistics Endpoints

- [ ] **GET /api/providers/:id/stats**
  - Повертає статистику для конкретного провайдера
  - Response: `ProviderStats`
  - Status: 200 OK

- [ ] **GET /api/providers/stats/overall**
  - Повертає загальну статистику по всіх провайдерах
  - Response: `OverallStats`
  - Status: 200 OK

## 📋 ЕТАП 2: WEBSOCKET INTEGRATION (Пріоритет: MEDIUM)

### 🔴 WebSocket Events

- [ ] **'provider:stats:update'**
  - Emits: Real-time statistics update
  - Payload: `{ providerId, stats: ProviderStats }`
  - Frequency: Every 30 seconds

- [ ] **'provider:status:change'**
  - Emits: Provider status change
  - Payload: `{ providerId, status: 'active' | 'inactive' | 'error' }`
  - Trigger: On status change

- [ ] **'model:request:complete'**
  - Emits: Model request completed
  - Payload: `{ providerId, modelId, latency, tokens, cost }`
  - Trigger: After each request

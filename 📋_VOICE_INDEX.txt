🎯 ЩО НОВОГО?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🔊 TTS: Piper замість Coqui
   ⚡ Швидше: 100x RT (vs 5x RT)
   💾 Легше: 50 MB (vs 2+ GB)
   💰 Дешевше: -75% CPU usage

🗣️ STT: Whisper Turbo замість base
   ⚡ Швидше: 10x RT (vs 3x RT)
   🎯 Точніше: 95%+ (vs 85%)
   💾 Оптимально: 1.5 GB (vs 5 GB total)

⚡ Нові оптимізації:
   • Silero VAD (голосова детекція)
   • faster-whisper (прискорення)
   • Vosk (легка альтернатива)

🐛 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Часті проблеми:

1. Piper не встановлюється
   → pip install --upgrade pip
   → pip install piper-tts --no-cache-dir

2. Whisper Turbo не знайдено
   → pip install --upgrade openai-whisper
   → Використайте model="turbo"

3. Помилка ONNX Runtime
   → pip install onnxruntime
   → pip install onnxruntime-cpu

4. Повільно на CPU
   → Використайте faster-whisper
   → compute_type="int8"

5. Українська модель не працює
   → Вручну завантажте з HuggingFace
   → Перевірте шлях до моделі

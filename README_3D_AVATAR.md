## 🎮 Як Користуватися

### Кнопки:

- 🎤 **Слухати** - аватар пульсує фіолетовим (режим слухання)
- 🧠 **Обробка** - аватар обертається синім (режим мислення)
- 💬 **Говорити** - аватар рухається рожевим (режим мовлення)
- 🔄 **Скинути** - повернення до початкового стану

### Що Ви Бачите:

- ✨ Анімований 3D аватар
- 👀 Очі, що моргають
- ⭐ Частинки навколо
- 🎨 Зміна кольорів при різних режимах

## ❓ Часті Питання

**Q: Чому порт 5090 не працює?**  
A: Проєкт НЕ використовує порт 5090. Аватар або відкривається прямо з HTML файлу, або на порту 3000 (frontend) або 8080 (demo server).

**Q: Аватар не анімується?**  
A: Натисніть на кнопки (Слухати, Обробка, Говорити) щоб побачити різні анімації.

**Q: Хочу побачити повний проєкт?**  
A: Запустіть `make dev` у директорії predator-analytics, потім відкрийте http://localhost:3000

## 🚢 PRODUCTION DEPLOY

### Kubernetes (Helm)

```bash
# 1. Підготовка
cd helm/predator-analytics
helm dependency update

# 2. Install
helm install predator-analytics . \
  -f values.yaml \
  -f values-prod.yaml \
  --namespace predator-analytics-production \
  --create-namespace

# 3. Перевірка
kubectl get pods -n predator-analytics-production
```

### ArgoCD (GitOps)

```bash
# Apply ArgoCD application
kubectl apply -f argocd/application.yaml

# ArgoCD автоматично синхронізує з Git
```

### Terraform

```bash
cd terraform
terraform init
terraform plan -var-file="production.tfvars"
terraform apply -var-file="production.tfvars"
```

```bash
make help          # Показати всі команди

make test          # Запустити тести

make db-backup     # Backup бази даних
make k8s-install   # Deploy в Kubernetes
```

### Docker Commands

```bash
docker-compose ps                    # Статус
docker-compose logs -f backend       # Логи backend
docker-compose exec backend bash     # Shell в backend
docker-compose restart frontend      # Перезапуск frontend
```

### Database Commands

```bash
# PostgreSQL shell
docker-compose exec postgres psql -U postgres -d predator_analytics

# Backup
make db-backup

# Migrations
docker-compose exec backend alembic upgrade head
```

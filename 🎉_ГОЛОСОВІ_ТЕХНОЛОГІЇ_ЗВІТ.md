## 🚀 ІНСТРУКЦІЯ ВИКОРИСТАННЯ

### Швидкий Старт (10 хвилин)

```bash
# 1. Встановлення
cd predator12-local
./install-voice-tech.sh

# 2. Тестування
source voice-env/bin/activate
python test_voice_system.py

# 3. Запуск API
python voice_api.py
```

### Використання з Python

```python
# TTS
from TTS.api import TTS
tts = TTS("tts_models/multilingual/multi-dataset/xtts_v2")
tts.tts_to_file(
    text="Привіт! Я голосовий асистент.",
    file_path="output.wav",
    language="uk"
)

# STT
from faster_whisper import WhisperModel
model = WhisperModel("base")
segments, info = model.transcribe("audio.wav", language="uk")
text = " ".join([s.text for s in segments])
```

### Використання з Frontend

```typescript
import { voiceAPI } from "./services/voiceAPI";

// TTS
const audioURL = await voiceAPI.textToSpeech("Привіт!", "uk");
await voiceAPI.playAudio(audioURL);

// STT
const audioBlob = await voiceAPI.recordAudio(5000);
const text = await voiceAPI.speechToText(audioBlob);
```

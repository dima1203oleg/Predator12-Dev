## 🚀 Для Повного Frontend з Next.js

Якщо хочете запустити повний frontend (потрібен Docker):

```bash
cd /Users/dima/Documents/Predator12/predator-analytics
docker-compose up -d frontend
```

Потім відкрийте: **http://localhost:3000**

## 🆘 Не Працює?

### Спосіб 1: Відкрити напряму
Натисніть правою кнопкою на файл `demo-avatar.html` → "Відкрити за допомогою" → Chrome/Safari/Firefox

### Спосіб 2: Створити простий сервер
```bash
cd /Users/dima/Documents/Predator12/predator-analytics
python3 -m http.server 8080
```

Потім відкрийте: **http://localhost:8080/demo-avatar.html**

---

## 📝 Примітка про Порти

- **demo-avatar.html** - НЕ потребує сервера, відкривається напряму
- **Frontend (Next.js)** - працює на порті **3000** (не 5090)
- **Backend API** - працює на порті **8000**
- **Grafana** - працює на порті **3001**

**Порт 5090 не використовується в цьому проєкті.**

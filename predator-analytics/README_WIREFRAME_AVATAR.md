## 💡 Кастомізація

Якщо хочете змінити кольори, відкрийте `index-main.html` та знайдіть:

```javascript
// Основний колір wireframe (зараз блакитний)
color: 0x00ffff;

// Колір очей (зараз блакитний)
color: 0x00ffff;

// Рожеві акценти
color: 0xff00ff;
```

Коди кольорів:

- `0x00ffff` - Блакитний (cyan)
- `0xff00ff` - Рожевий (magenta)
- `0x00ff00` - Зелений
- `0xff0000` - Червоний
- `0xffffff` - Білий

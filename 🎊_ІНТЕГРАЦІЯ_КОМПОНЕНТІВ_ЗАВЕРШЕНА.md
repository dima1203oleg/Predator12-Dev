## 📋 ФУНКЦІОНАЛЬНІ МОЖЛИВОСТІ

### ModelConfigDialog:

✅ Вибір моделей для кожного акаунту  
✅ Конфігурація параметрів (temperature, top_p, max_tokens, etc.)  
✅ Тестування підключення з показом латентності  
✅ Presets для різних типів моделей (reasoning, code, vision, quick)  
✅ Валідація: збереження лише після успішного тесту

### ProviderStatsDashboard:

✅ Overall statistics (загальні запити, success rate, латентність, вартість)  
✅ Provider-specific cards (окремі метрики для кожного провайдера)  
✅ Auto-refresh кожні 30 секунд  
✅ Кольорові індикатори (excellent/good/warning/critical)  
✅ Top model indicator для кожного провайдера  
✅ Progress bars (success vs failed requests)

### ModelProviderManager:

✅ Перемикання Models/Agents  
✅ Фільтрація за категоріями  
✅ Додавання провайдерів з множинними акаунтами  
✅ Управління API ключами  
✅ Активація/деактивація акаунтів  
✅ Редагування та видалення акаунтів  
✅ Статистика використання для кожного провайдера

## 🔌 BACKEND INTEGRATION REQUIREMENTS

### API Endpoints потрібні:

#### 1. Provider Management:

```typescript
GET    /api/providers                    // Список всіх провайдерів
POST   /api/providers                    // Додати новий акаунт
PUT    /api/providers/:id                // Оновити акаунт
DELETE /api/providers/:id                // Видалити акаунт
```

#### 2. Model Configuration:

```typescript
GET    /api/providers/:id/models         // Моделі акаунту
POST   /api/providers/:id/models/config  // Зберегти конфігурацію
POST   /api/providers/:id/test           // Тест підключення
```

#### 3. Statistics:

```typescript
GET    /api/providers/:id/stats          // Статистика провайдера
GET    /api/providers/stats/overall      // Загальна статистика
```

#### 4. WebSocket Events:

```typescript
"provider:stats:update"; // Real-time stats update
"provider:status:change"; // Provider status change
"model:request:complete"; // Request completed
```

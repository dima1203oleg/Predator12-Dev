                         🔧 TROUBLESHOOTING

    Problem: Frontend won't start
    Solution: cd predator12-local/frontend && rm -rf node_modules && npm i

    Problem: Graph not showing
    Solution: npm install cytoscape @types/cytoscape

    Problem: Backend not responding
    Solution: pkill -f uvicorn && uvicorn app.main:app --reload --port 8000

    Problem: Voice input not working
    Solution: Use Chrome/Edge, grant microphone permission

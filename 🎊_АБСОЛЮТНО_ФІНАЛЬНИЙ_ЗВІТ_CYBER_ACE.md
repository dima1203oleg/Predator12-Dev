## 🐛 TROUBLESHOOTING

### Backend не запускається

**Проблема:** Port 8000 зайнятий

**Рішення:**
```bash
lsof -ti:8000
kill -9 $(lsof -ti:8000)
./cyber-ace.sh start
```

### Frontend не підключається

**Проблема:** CORS помилки

**Рішення:**
```bash
# Перевірити .env.development
cat frontend/.env.development

# Має бути:
# VITE_API_BASE_URL=http://localhost:8000
```

### Залежності відсутні

**Проблема:** ModuleNotFoundError або npm errors

**Рішення:**
```bash
./cyber-ace-install.sh
```

### Детальний Troubleshooting

Дивіться: **🎯_ACTION_PLAN_CYBER_ACE.md** (розділ Troubleshooting)

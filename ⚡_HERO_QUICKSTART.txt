   http://localhost:5173

   • AI обличчя з неоновою сіткою

   • Стрім агентських подій

═════════════════════════════════

📦 ЯКЩО ПЕРШИЙ РАЗ:

cd predator12-local/frontend
npm install
npm run dev

═════════════════════════════════

🎨 ЩО ПРАЦЮЄ:

✅ /frontend/src/pages/Home.tsx        → Головна сторінка
✅ /frontend/src/components/Hero/      → Всі компоненти
✅ /frontend/src/styles/hero.css       → Неонові стилі
✅ Cytoscape, framer-motion            → Встановлено
✅ Voice I/O (uk-UA)                   → Web Speech API
✅ SSE events                          → /api/events
✅ Chat                                → /api/chat

═════════════════════════════════

🔧 BACKEND ТРЕБА ЗАПУСТИТИ:

cd predator12-local/backend
source venv/bin/activate
uvicorn app.main:app --reload

Або додай endpoints:
• POST /api/chat
• GET /api/events (SSE)

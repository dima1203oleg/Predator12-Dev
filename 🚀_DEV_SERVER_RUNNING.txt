📊 МЕТРИКИ ДЛЯ ТЕСТУВАННЯ

   TTFI (Time to First Interaction):
      Ціль:      < 2.5 секунди
      Як:        Від завантаження до першої можливості взаємодії
      Вимірюй:   Chrome DevTools → Performance → FCP / TTI

   FPS (Frames Per Second):
      Ціль:      ≥ 50 FPS
      Як:        DevTools → Performance → Frames
      Важливо:   3D голова не має лагати

   ASR Accuracy (Speech Recognition):
      Ціль:      ≥ 85% точність
      Українська: Протестуйте 10 фраз
      Англійська: Протестуйте 10 фраз
      Запишіть:   Скільки розпізнано правильно

   TTS Quality (Text-to-Speech):
      Українська: Чи зрозуміло?
      Англійська: Чи зрозуміло?
      Швидкість:  Чи комфортна?

🐛 ЯКЩО ЩОСЬ НЕ ПРАЦЮЄ

   Сторінка не завантажується:
      1. Перевірте консоль браузера (F12)
      2. Перевірте Network tab (чи є failed requests)
      3. Спробуйте перезавантажити сторінку

   3D не відображається:
      1. Перевірте WebGL: chrome://gpu/
      2. Консоль: console.log(window.THREE)
      3. Спробуйте інший браузер

   Мікрофон не працює:
      1. Перевірте дозволи браузера
      2. Консоль: navigator.mediaDevices.getUserMedia
      3. Спробуйте HTTPS (деякі браузери вимагають)

   TTS не промовляє:
      1. Консоль: window.speechSynthesis
      2. Перевірте volume системи
      3. Спробуйте інший браузер

   Граф не інтерактивний:
      1. Перевірте console на помилки
      2. Спробуйте resize вікна
      3. Перевірте CSS (Network tab)

📡 API ENDPOINTS
═══════════════════════════════════════════════════════════════════

🎤 TTS (Text-to-Speech):
   POST http://localhost:8000/api/tts
   Body: {
     "text": "Привіт!",
     "language": "uk",
     "provider": "auto"
   }

🎧 STT (Speech-to-Text):
   POST http://localhost:8000/api/stt
   Body: FormData with audio file

📊 Capabilities:
   GET http://localhost:8000/api/capabilities

🏥 Health Check:
   GET http://localhost:8000/health

📚 Документація:
   http://localhost:8000/docs

🔧 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

❌ API не запускається:
   pip3 install -r voice-requirements.txt
   lsof -i :8000 && kill -9 <PID>

❌ Моделі не завантажуються:
   python3 -c "from TTS.api import TTS; TTS('tts_models/multilingual/multi-dataset/xtts_v2')"
   python3 -c "import whisper; whisper.load_model('base')"

❌ API keys не працюють:
   echo $ELEVENLABS_API_KEY
   export ELEVENLABS_API_KEY="your_key"

❌ Browser API не працює:
   Використовуйте HTTPS
   Дозвольте доступ до мікрофона
   Перевірте підтримку браузера

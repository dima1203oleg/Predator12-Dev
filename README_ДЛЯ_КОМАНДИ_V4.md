## 🛠️ ТЕХНІЧНІ ДЕТАЛІ

### Технології
- **Frontend**: React 18 + TypeScript
- **UI Framework**: Material-UI 5
- **Анімації**: Framer Motion
- **Bundler**: Vite
- **Стилі**: CSS-in-JS + Custom themes

### Структура
```
frontend/
├── src/
│   ├── components/
│   │   ├── analytics/          # Модуль аналітики
│   │   ├── security/           # Кібербезпека
│   │   ├── research/           # Дослідження
│   │   ├── data/              # Управління даними
│   │   ├── dashboard/         # Головний дашборд
│   │   ├── agents/            # AI агенти
│   │   ├── models/            # Хаб моделей
│   │   ├── monitor/           # Моніторинг
│   │   ├── accessibility/     # Доступність
│   │   ├── game/              # Ігрові елементи
│   │   ├── effects/           # Візуальні ефекти
│   │   └── theme/             # Система тем
│   ├── theme/                 # Nexus theme
│   ├── contexts/             # React Context
│   └── styles/               # CSS стилі
└── public/                   # Статичні файли
```

## 🔧 РОЗРОБКА

### Додавання нових модулів
1. Створіть компонент у відповідній папці
2. Додайте імпорт в `App.tsx`
3. Додайте в навігаційний масив `navigationModules`
4. Додайте рендер логіку в основний switch

### Стилізація
- Використовуйте `nexusTheme` для кольорів
- Дотримуйтесь існуючих patterns
- Тестуйте на різних розмірах екранів

### Анімації
- Використовуйте Framer Motion для складних анімацій
- Дотримуйтесь performance best practices
- Додавайте `prefers-reduced-motion` support

## 🐛 TROUBLESHOOTING

### Проблеми з запуском
```bash
# Очистити кеш та перевстановити залежності
rm -rf node_modules package-lock.json
npm install
```

### Проблеми з портами
```bash
# Перевірити які порти зайняті
lsof -ti:5093
# Завершити процес якщо потрібно
kill -9 <PID>
```

### Проблеми з TypeScript
```bash
# Перевірити типи
npm run typecheck
```

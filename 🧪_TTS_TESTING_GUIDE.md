# 🎤 Тестування голосового інтерфейсу

## Кроки для перевірки TTS

### 1. Відкрийте додаток
- Запустіть frontend (`npm start`)
- Перейдіть до голосового інтерфейсу

### 2. Перевірте консоль браузера
Натисніть F12 та перевірте логи:

```
✅ Speech Synthesis доступний
🎤 Завантажено голосів: X
📋 Перші 5 голосів: [список голосів]
🇺🇦 Українські голоси: [українські голоси або порожній масив]
```

### 3. Тестування TTS
1. **Натисніть "Тест Browser"** - має відразу озвучити повідомлення
2. **Натисніть "Тест голосу"** - тест Premium FREE системи
3. **Використайте мікрофон** - скажіть "привіт"

### 4. Очікувані результати

#### При натисканні "Тест Browser":
```
🌐 Fallback до Browser Speech API...
🔊 Browser TTS: "Тест браузерного озвучування..."
⚙️ Browser TTS налаштування: {lang: "uk-UA", rate: 1, pitch: 1, volume: 0.8}
🎤 Доступно голосів: X
🎵 Використовується голос: [назва] uk-UA
🚀 Запуск Browser TTS...
🔊 Browser TTS ПОЧАТОК: Тест браузерного озвучування...
✅ Browser TTS ЗАВЕРШЕНО
```

#### При голосовій команді "привіт":
```
🎤 Обробка команди: "привіт" (впевненість: 90%)
🤖 AI відповідь: "Привіт! Я ваш персональний AI асистент..."
🔊 Початок озвучування відповіді...
🌐 Використовуємо Browser Speech API...
[далі логи TTS як вище]
```

### 5. Якщо не працює

#### Проблема: Немає українських голосів
```javascript
// В консолі браузера
const voices = speechSynthesis.getVoices();
console.log('Всі голоси:', voices.map(v => `${v.name} (${v.lang})`));

// Знайти англійські голоси як fallback
const enVoices = voices.filter(v => v.lang.includes('en'));
console.log('Англійські голоси:', enVoices.map(v => v.name));
```

#### Проблема: Взагалі немає звуку
1. Перевірте гучність системи
2. Закрийте інші програми що використовують аудіо
3. Спробуйте інший браузер (Chrome рекомендується)

#### Проблема: Помилки в консолі
- `speechSynthesis is undefined` - браузер не підтримує
- `voices array empty` - голоси не завантажилися, почекайте
- `speak() failed` - можлива блокировка автовідтворення

### 6. Налаштування для кращої роботи

#### Chrome:
1. chrome://settings/content/sound
2. Дозволити звук для сайту
3. Вимкнути блокування автовідтворення

#### Зміна мови на англійську (якщо немає українських голосів):
1. Відкрийте налаштування голосового інтерфейсу
2. Змініть мову на "en-US"
3. Протестуйте знову

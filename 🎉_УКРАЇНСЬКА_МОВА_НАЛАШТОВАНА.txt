  2. Header: "AI-Асистент" ✅
  3. Chat placeholder: "Напишіть повідомлення..." ✅

  5. console.log(document.documentElement.lang) => "uk" ✅

  1. Press M (мікрофон)
  2. Speak Ukrainian
  3. Check recognition.lang === 'uk-UA' ✅
  4. Type: "Привіт" → Send
  5. Check Ukrainian TTS voice ✅

  1. Click dropdown в header
  2. Select 🇬🇧 English
  3. UI changes to English ✅
  4. Select 🇺🇦 Українська
  5. UI повертається до української ✅

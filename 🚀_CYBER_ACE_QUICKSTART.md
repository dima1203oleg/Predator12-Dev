## 🎮 Як Користуватись

### Голосове Управління

1. **Натиснути мікрофон** 🎤
2. **Дозволити доступ** до мікрофона (якщо запитає браузер)
3. **Говорити команду** українською або англійською
4. **Команда автоматично розпізнається** та відображається у полі
5. **Натиснути "Надіслати"** або просто відпустити мікрофон

**Приклади команд:**
- "Проаналізуй дані"
- "Виявити ризики"
- "Показати агентів"
- "Дослідити мережу"

### Текстове Управління

1. **Ввести текст** у поле
2. **Натиснути Enter** або кнопку "Надіслати"

### Швидкі Дії

Натиснути на одну з 6 швидких дій:
- 📊 Проаналізувати дані
- 🔍 Виявити ризики
- 🕸️ Дослідити мережу
- 🛡️ Перевірити відповідність
- 🎯 Знайти загрози
- 🔮 Знайти паттерни

### Агенти

1. **Натиснути "Показати агентів"**
2. **Панель з'являється справа**
3. **Вибрати агента** для деталей
4. **Натиснути "Активувати"** для роботи з агентом

## 🐛 Типові Проблеми

### "Мікрофон не працює"

**Причина:** Браузер не має доступу до мікрофона

**Рішення:**
1. Перевірити дозволи браузера (Settings → Privacy → Microphone)
2. Використовувати Chrome (найкраща підтримка)
3. HTTPS потрібен для production (localhost працює без HTTPS)

### "Web Speech API not supported"

**Причина:** Браузер не підтримує Web Speech API

**Рішення:**
- Використовувати Chrome, Edge або Firefox
- Safari має обмежену підтримку
- Fallback на текстовий ввід

### "Компоненти не завантажуються"

**Причина:** Не встановлені залежності

**Рішення:**
```bash
npm install three @react-three/fiber @react-three/drei zustand framer-motion i18next react-i18next
```

### "Three.js лагає"

**Причина:** Слабка відеокарта або багато частинок

**Рішення:**
- Зменшити кількість частинок в `AceAvatar.tsx`
- Вимкнути `autoRotate` в OrbitControls
- Зменшити `dpr` в Canvas

## 📚 Документація

### Структура Модуля

```
cyber-ace/
├── CyberAcePage.tsx          # Головна сторінка
├── components/               # Компоненти
│   ├── AceAvatar.tsx        # 3D аватар
│   ├── VoiceInput.tsx       # Голосовий ввід
│   ├── QuickActions.tsx     # Швидкі дії
│   ├── AgentCards.tsx       # Картки агентів
│   ├── StatusBar.tsx        # Статус-бар
│   └── index.ts             # Barrel export
├── state/
│   └── cyberAceStore.ts     # Zustand store
├── locales/                 # Переклади
│   ├── uk-UA.json           # Українська
│   └── en-US.json           # Англійська
├── styles/
│   └── cyber-ace.css        # Стилі
└── README.md                # Детальна документація
```

### Store API

```typescript
// Отримати стан
const { agents, tasks, currentAgent } = useCyberAceStore();

// Додати завдання
addTask({
  id: 'task-1',
  agentId: 'data-analyst-01',
  title: 'Аналіз даних',
  status: 'pending',
  priority: 'high'
});

// Оновити агента
updateAgent('data-analyst-01', { status: 'busy' });

// Делегувати завдання
delegateTask('task-1', 'data-analyst-01');
```

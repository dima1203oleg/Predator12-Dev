✅ Всі залежності автоматично

source voice-env/bin/activate

Перевірить:
✅ TTS - озвучування українською
✅ STT - розпізнавання мовлення
✅ Якість та швидкість

─────────────────────────────────────────────────────────────

🌐 КРОК 3: ЗАПУСК API (1 хвилина)

python voice_api.py

API буде доступний:
📍 http://localhost:8000
📚 Документація: http://localhost:8000/docs

─────────────────────────────────────────────────────────────

🎯 КРОК 4: ВИКОРИСТАННЯ (2 хвилини)

A) З PYTHON:
```python
from TTS.api import TTS
tts = TTS("tts_models/multilingual/multi-dataset/xtts_v2")
tts.tts_to_file(text="Привіт!", file_path="out.wav", language="uk")
```

B) З API:
```bash
curl -X POST "http://localhost:8000/api/tts" \
  -H "Content-Type: application/json" \
  -d '{"text":"Привіт!","language":"uk"}'
```

C) З FRONTEND:
```typescript
import { voiceAPI } from './services/voiceAPI';
const audio = await voiceAPI.textToSpeech("Привіт!", "uk");
await voiceAPI.playAudio(audio);
```

🎤 ШВИДКІ КОМАНДИ:

# Активувати середовище

# Запустити API
python voice_api.py

# Тестувати систему
python test_voice_system.py

# Згенерувати аудіо

# Розпізнати аудіо
python -c "from faster_whisper import WhisperModel; print(WhisperModel('base').transcribe('test.wav')[0])"

## 🆘 TROUBLESHOOTING

### Проблема: TypeScript не бачить модулі

**Рішення**:

```
Cmd+Shift+P → "TypeScript: Restart TS Server"
```

### Проблема: Помилки компіляції

**Перевірка**:

```bash
cd predator12-local/frontend
npx tsc --noEmit
```

### Проблема: Dev server не запускається

**Рішення**:

```bash
npm install
npm run dev
```

### Проблема: Компоненти не рендеряться

**Перевірка**: Консоль браузера (F12) → перегляд runtime помилок

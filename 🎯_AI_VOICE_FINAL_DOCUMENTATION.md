#### STT (Розпізнавання):

1. Клацніть кнопку мікрофона 🎤
2. Дозвольте доступ до мікрофона
3. Скажіть щось українською або англійською

1. Введіть текст або отримайте відповідь від AI
2. Натисніть кнопку "Озвучити" 🔊
3. Система автоматично вибере голос відповідно до мови

#### Перемикання Мови:

1. Знайдіть селектор мови в інтерфейсі
2. Виберіть "Українська" або "English"
3. Всі елементи UI та голосові функції перемкнуться

## 🔧 ТЕХНІЧНІ ДЕТАЛІ

### STT Конфігурація

```typescript
// Українська мова за замовчуванням

recognition.lang = "uk-UA"; // Або 'en-US' для англійської

recognition.interimResults = true;
```

### TTS Конфігурація

```typescript
// Пріоритет голосів
1. uk-UA (українські голоси)
2. ru-RU (російські голоси як fallback)
3. Будь-який системний голос
```

### Підтримувані Мови

- **Українська (uk-UA)** - основна мова ✅
- **Англійська (en-US/en-GB)** - додаткова мова ✅
- **Російська (ru-RU)** - видалена з UI, використовується тільки як TTS fallback

## 🐛 НАЛАГОДЖЕННЯ

### Перевірка Доступних Голосів

```javascript
// У консолі браузера:
window.speechSynthesis.getVoices().forEach((voice) => {
  console.log(voice.name, voice.lang);
});
```

### Часті Проблеми та Рішення

#### 1. STT не працює

**Симптоми:** Мікрофон не активується або не розпізнає мову

**Рішення:**

- Перевірте дозволи браузера на мікрофон
- Переконайтесь, що використовуєте HTTPS або localhost
- Спробуйте інший браузер (Chrome/Edge рекомендовано)
- Перевірте, чи мікрофон працює в інших програмах

```javascript
// Перевірка підтримки
if (!("webkitSpeechRecognition" in window)) {
  console.error("Speech Recognition не підтримується");
}
```

#### 2. TTS не озвучує

**Симптоми:** Текст не озвучується або озвучується не тією мовою

**Рішення:**

- Перевірте доступні голоси в системі
- Встановіть українські голоси в налаштуваннях ОС
- Дочекайтесь завантаження голосів (може зайняти 1-2 секунди)

```javascript
// Примусове завантаження голосів
window.speechSynthesis.getVoices();
setTimeout(() => {
  window.speechSynthesis.getVoices();
}, 1000);
```

#### 3. UI не перемикає мову

**Симптоми:** Текст залишається однією мовою після перемикання

**Рішення:**

- Перевірте стан `language` у компоненті
- Перезавантажте сторінку
- Очистіть кеш браузера

```javascript
// Перевірка поточної мови
console.log("Current language:", this.state.language);
```

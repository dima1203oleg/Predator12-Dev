  setSelectedAccountForConfig(account);

</IconButton>

// Додати діалог конфігурації

  <ModelConfigDialog

    accountId={selectedAccountForConfig.id}
    accountName={selectedAccountForConfig.accountName}
    providerName={selectedAccountForConfig.providerName}
    models={selectedAccountForConfig.models || []}
  />
)}

## 📚 USE CASES

### Use Case 1: Налаштування моделі

```
1. Клік на Settings button біля акаунту
2. Відкриється ModelConfigDialog
3. Вибрати модель зі списку
4. Налаштувати параметри за допомогою sliders
5. Натиснути "Test Connection"
6. Якщо успішно → Enable "Save Configuration"
7. Зберегти
```

### Use Case 2: Моніторинг провайдерів

```
1. Перейти на вкладку "Statistics"
2. Побачити загальну статистику
3. Переглянути детальні метрики кожного провайдера
4. Enable auto-refresh для реал-тайм моніторингу
5. Клікнути refresh на конкретному провайдері для оновлення
```

### Use Case 3: Оптимізація performance

```
1. Відкрити Statistics
2. Знайти провайдера з високою латентністю
3. Клікнути Settings → Configure model
4. Зменшити max_tokens або temperature
5. Test connection для перевірки
6. Save якщо покращилось
```

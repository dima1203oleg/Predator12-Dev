## 🎧 ТЕСТУВАННЯ STT (Speech-to-Text)

### Українська мова 🇺🇦

#### Базові тести
- [ ] Кнопка мікрофона активується
- [ ] Браузер запитує дозвіл на мікрофон
- [ ] Індикатор показує, що запис активний
- [ ] Просте слово розпізнається: "Привіт"
- [ ] Коротка фраза розпізнається: "Як справи?"
- [ ] Довга фраза розпізнається: "Покажи прогноз погоди на завтра"

#### Детальні тести
- [ ] Розпізнавання з першої спроби
- [ ] Правильне відображення українських літер (і, ї, є, ґ)
- [ ] Розпізнавання чисел: "один", "два", "три"
- [ ] Розпізнавання дат: "сьогодні", "завтра", "вчора"
- [ ] Розпізнавання команд: "відкрий", "закрий", "покажи"

#### Тривалість і стабільність
- [ ] Continuous listening працює >30 секунд
- [ ] Множинні фрази розпізнаються підряд
- [ ] Немає несподіваних зупинок
- [ ] Confidence score >0.7 для чітких фраз

### Англійська мова 🇬🇧

#### Перемикання мови
- [ ] Налаштування відкриваються
- [ ] Є опція вибору "English"
- [ ] Після вибору мова змінюється
- [ ] Інтерфейс оновлюється англійською

#### Базові тести англійською
- [ ] Просте слово: "Hello"
- [ ] Коротка фраза: "How are you?"
- [ ] Довга фраза: "Show me the weather forecast"
- [ ] Команди: "Open", "Close", "Show me"

## 🔊 ТЕСТУВАННЯ TTS (Text-to-Speech)

### Українська мова 🇺🇦

#### Автоматичне озвучування
- [ ] Після розпізнавання текст озвучується
- [ ] Голос звучить природньо
- [ ] Використовується український голос
- [ ] Швидкість озвучування прийнятна
- [ ] Гучність достатня

#### Ручне озвучування
- [ ] Кнопка тестового озвучування працює
- [ ] Тестовий текст озвучується українською
- [ ] Можна зупинити озвучування
- [ ] Можна відтворити повторно

#### Різні типи тексту
- [ ] Прості слова: "Привіт", "Дякую"
- [ ] Фрази: "Доброго ранку", "На добраніч"
- [ ] Числа: "один", "десять", "сто"
- [ ] Запитання: "Як справи?", "Що нового?"

### Англійська мова 🇬🇧

#### Після перемикання на англійську
- [ ] Озвучування працює англійською
- [ ] Голос англомовний
- [ ] Вимова правильна
- [ ] Інтонація природна

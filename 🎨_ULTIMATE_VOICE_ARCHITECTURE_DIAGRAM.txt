CACHING LAYER
═══════════════════════════════════════════════════════════════════

┌───────────────────────────────────────────────────────────────┐
│                      💾 CACHE SYSTEM                          │
├───────────────────────────────────────────────────────────────┤
│                                                               │
│  Request Hash: MD5(text + language + speed)                  │
│                                                               │
│  Cache Hit?                                                   │
│    ├─✅ Yes → Return cached audio (instant)                  │
│    │                                                          │
│    └─❌ No  → Process request through fallback chain         │
│              → Cache result for future                        │
│                                                               │
│  Cache Storage:                                               │
│    • Location: static/audio/                                  │
│    • Format: WAV/MP3                                          │
│    • TTL: Configurable                                        │
│    • Size limit: 1 GB                                         │
│                                                               │
└───────────────────────────────────────────────────────────────┘

✅ Privacy - Local fallback для sensitive data

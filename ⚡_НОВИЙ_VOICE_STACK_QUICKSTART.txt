🔧 КРОК 4: ІНТЕГРАЦІЯ В API

# Оновити voice_api.py
nano voice_api.py

Додати Piper backend:
```python
# Замість Coqui TTS
from piper import PiperVoice

voice = PiperVoice.load("models/piper/uk_UA-ukrainian-medium.onnx")
audio = voice.synthesize(text)
```

Додати Whisper Turbo:
```python
# Замість base/small
import whisper

model = whisper.load_model("turbo")
result = model.transcribe(audio_path, language="uk")
```

# Запустити оновлений API

🌐 КРОК 5: ІНТЕГРАЦІЯ У ФРОНТЕНД

Немає змін! TypeScript SDK залишається той самий:

```typescript
import { VoiceAPIClient } from './services/voiceAPI';

const voiceAPI = new VoiceAPIClient('http://localhost:8000');

// TTS (тепер використовує Piper)
const audioBlob = await voiceAPI.synthesizeSpeech({
  text: "Привіт!",
  language: "uk"
});

// STT (тепер використовує Whisper Turbo)
const text = await voiceAPI.recognizeSpeech(audioBlob, "uk");
```

Fallback (Web Speech API) залишається без змін!

🐛 TROUBLESHOOTING

❓ Piper не встановлюється
→ pip install --upgrade pip
→ pip install piper-tts --no-cache-dir

❓ Whisper Turbo не знайдено
→ pip install --upgrade openai-whisper
→ Використайте model="turbo" замість "large-v3-turbo"

❓ Помилка ONNX Runtime
→ pip install onnxruntime
→ Або використайте CPU версію: onnxruntime-cpu

❓ Українська модель не завантажується
→ Вручну завантажте з:
  https://huggingface.co/rhasspy/piper-voices

❓ Повільний Whisper на CPU
→ Використайте faster-whisper:
  from faster_whisper import WhisperModel
  model = WhisperModel("base", device="cpu")
